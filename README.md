# OSTO Paste

Paste copied text into game chat. Made for Old School TERA's Toolbox.
Based on [tera-paste](https://github.com/Cybours/tera-paste) by Cybours.

## Install
Put `module.json` in `toolbox\mods\osto-paste\` and start Toolbox. It downloads the rest and keeps the mod updated.
Remove the old `paste` or `tera-paste-master` folder if you have one.

## Commands
Copy text, then type in the Toolbox chat (`/8`):

| Command | Sends to |
| --- | --- |
| `paste s` | Say |
| `paste p` | Party |
| `paste pn` | Party notice |
| `paste g` | Guild |
| `paste i` | Raid |
| `paste in` | Raid notice |
| `paste c` | Global |
| `paste w Name` | Whisper to Name |
| `paste test` | Only you (nothing is sent) |
| `paste` | Turn the mod on or off |

Line breaks in the copied text become spaces.
